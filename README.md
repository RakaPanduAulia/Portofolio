# Raka Pandu Aulia — Portfolio

Personal portfolio website of **Raka Pandu Aulia** — Game Programmer · Game Artist · Software Engineer, based in Bandung, Indonesia.

A single-page, dark-themed portfolio showcasing game development work, professional
experience, achievements, and skills.

## Live site

Once GitHub Pages is enabled: **https://rakapanduaulia.github.io/portfolio/**

## Sections

- **Home** — intro, headline, and quick tags
- **About** — background, education (D3 Telkom RPLA, ongoing S1 Computer Science @ BINUS), languages
- **Projects** — Voluspá, KICKOFF LAND!, Gourmet Guardians, Otherworldly Hearts, SAMIRA
- **Achievements** — Best Local Game, People's Choice Award, VSGA Junior Game Programmer
- **Experience** — Bank Teller (BCA), Game Programmer (Cliffbite), Infinite Learning internships, HIMADIRA org roles
- **Skills** — game dev, VR/MR, art & animation, and tools
- **Contact** — Linktree and social links

## Tech stack

- Plain **HTML5**
- **Tailwind CSS** (via CDN)
- Minimal **vanilla JavaScript** (mobile menu, scroll reveal)

No build step — just open `index.html` or serve the folder statically.
